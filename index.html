📊 So sánh Tổng thửa – Nhóm 1 – Nhóm 2 giữa 2 kỳ

Nhập 2 file "Bảng tổng hợp kết quả rà soát, phân loại thửa đất cấp tỉnh" (Kỳ trước & Kỳ này) để so sánh theo từng đơn vị hành chính cấp xã.

1 Chọn file 2 kỳ

📄 File Kỳ trước
Bấm hoặc kéo-thả file .xlsx vào đây
📄 File Kỳ này
Bấm hoặc kéo-thả file .xlsx vào đây

2 Bảng chi tiết theo đơn vị

Khớp đơn vị theo Mã đơn vị hành chính cấp xã (cột B trong file gốc); nếu không có Mã đơn vị sẽ khớp theo Tên đơn vị. Tỷ lệ Nhóm 1 / Nhóm 2 = Khối lượng nhóm ÷ Tổng số thửa của đơn vị đó, trong kỳ tương ứng. Cột "So sánh tăng giảm" = số liệu Kỳ này − Kỳ trước (số dương = tăng, số âm = giảm).
